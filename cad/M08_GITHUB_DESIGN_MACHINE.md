# M08 — GitHub Actions as the CAD execution machine

**Goal:** ChatGPT (or any AI) is the conductor, **not the geometric authority**. AI writes or proposes a strictly typed input job and can review machine evidence. GitHub Actions executes versioned geometry code using the source file committed to the repository. **The AI must never claim a design exists merely because it drafted a job.** A machine job is accepted only if source hashes, IFC/DXF/STEP geometry tests, independent manifests and read-back pass.

## Current architecture

```text
AI or human produces design proposal (not final facts)
  -> Pull request containing source / job JSON (reviewable diff)
  -> GitHub Actions (read-only identity; pinned Python dependency versions)
  -> source SHA256, schema, status, dimensions, opening/host validation
  -> IfcOpenShell IFC4 + true IfcRelVoidsElement
  -> OpenCascade boolean-cut true solids + STEP
  -> ezdxf plan entities + opening REVIEW markers
  -> machine-generated SVG plan, section, HTML
  -> independent test suite + artifact SHA256 and manifest read-back
  -> Actions review artifact and public synthetic-only Pages preview
  -> human / authorized engineering QA (still required)
```

## Execute without ChatGPT computation

Use [Actions / CAD M08 Deterministic Design Machine](https://github.com/FabinGurung/JP_Computer-Aided-Drawings/actions/workflows/cad-m08-machine.yml). Choose **Run workflow** on main and preset `synthetic-building`. It can be invoked repeatedly: the source input is an allowlisted repository file, not a remote URL or an AI expression. It runs on GitHub-hosted runners without a ChatGPT computer or tool call, and saves `m08-synthetic-design-review` with a 14-day Actions artifact retention. `index.html` and SVGs can be opened locally; DXF, IFC and STEP are stored in the artifact. The public synthetic example on Pages is generated during the Pages build by the same CLI.

The source file is `design_jobs/synthetic/m08_demo.source.json`, and the tiny job file is `design_jobs/synthetic/m08_demo.job.json`. Any dimension adjustment changes the source file hash: **update the committed job's SHA256 too**, review the change, and rerun validation. No calculation is passed through ChatGPT. Element record types currently include **footing, column, beam, slab and wall**, plus hosted rectangular wall openings. Three-dimensional openings are actually cut in OCCT and semantically related as IFC4 `IfcOpeningElement` + `IfcRelVoidsElement`. Plan DXF opening segments are **annotations**, not falsely claimed DXF booleans.

Input units are millimetres, Z up. Rectangular solids use explicit x/y/z origin and length/width/height; section plane is explicitly supplied in source. All IDs and input relationships are checked, with actual source hashes and output manifests. No geometry values are filled automatically or guessed.

## Fail-closed acceptance rules

- Missing dimensions, invalid units, duplicate IDs, negative or zero dimensions, unsupported types, out-of-host openings, overlapping openings, unknown levels, altered source bytes, real-client source paths, and claims of field approval cause **job rejection**.
- IFC/DXF/STEP generated by **independent native parsers** are inspected, with OpenCascade solid-volume checking for actual wall voids.
- The machine manifest lists IDs, source SHA, job SHA, SHA256 per artifact, preview images, QA state, `engineering_approval=HOLD`, and `quantity_takeoff=BLOCKED`.
- Public GitHub Actions is **synthetic-only**. Never upload private source DXFs, licensed drawings or client personal data to public Actions/artifacts/Pages.
- A future **private** repository/runner with authorized Google Drive credentials can run identical code on private client documents. Such a runner **is not configured by M08**.
- An AI can hallucinate the requested inputs, and software can have bugs. No engineer can promise zero hallucinations or 100/100 real-world correctness. The reliable promise is **no silent substitution:** unverifiable evidence leads to HOLD/REJECT, with observable tests and traceable output.

## Remaining for a full construction-grade CAD

More complex rotated geometry, staircases, curves, hosted doors/windows, IFC authoring/round-trip and 3D web authoring, architectural design constraints, 2D dimension annotations/printing, independently checked engineering and source-revision approvals, private project storage and actual digital signing. None are implied by a successful synthetic build.

M08 does not redesign the existing CAD Studio page; final presentation can be decided separately. Rollback branch: `snapshot/pre-m08-actions-design-engine-20261011`.
