02 · Keep the current URL

A logical ID stays constant, for example AAD-ASHOK-ENG-001. The revision becomes AAD-ASHOK-ENG-001-R000001, then …-R000002. Later revisions update the same native Google Doc ID.

Read current

Resolve the document, relevant tabs, content hash and provider revision.

Copy to archive

Duplicate the complete current document under its existing revision ID. Read the copy back before editing current.

Update in place

Use a revision-guarded write on the same current Doc. Increment the revision by exactly one.

Verify the receipt

Record archive identity, before/after hashes and successful current readback. Current URL stays unchanged.

First creation is allowed once for a new logical ID. A failed archive or concurrent edit stops the update. Do not replace current with another newly created document.

Actions validates this transaction contract and its receipts. Native Drive copying/editing requires the authorized connector or an authenticated owner worker; this static website has no Drive credentials.

Separate the version sequences

  • Project edition v1: the preserved coordinated architectural baseline. Keep its archive and immutable Git commit available.
  • Project edition v2: the current coordination edition with MEP, site pins, workbook and usability repairs. The earlier v1 CAD export remains a v1 deliverable.
  • Source revisions: REV04, source v0.8 and retained QA02 filenames identify source records; they do not rename the project edition.
  • Shared template: 0.3.2 versions reusable engine/interface behavior independently of any house edition.
  • Maintained documents: R000001, R000002 and later revisions advance within the same logical and native provider ID under the archive-before-update policy above.

A contents or usability repair can remain within the current project edition. State precisely which sequence changes; never relabel an old export as a newer model.

03 · Code rules before release

Open the Nepal / Pokhara Code Library ↗

Resolve country, municipality, ward, occupancy, parcel zoning and current code editions for each project. National rules and municipal clauses have separate scopes. A current amendment notice without its readable text is an evidence gap, not a numeric rule.

Each constant records a clause and official source. Unknown values remain unknown. A prescriptive coverage limit is checked only for that design route; a project outside it needs project-specific engineering.

04 · A label cannot replace evidence

Structure & foundations

Actual sections require traceable loads, analysis, detailing and site bearing/groundwater evidence. Display glyphs and neighbouring houses do not supply them.

MEP & onsite wastewater

Keep drinking water, sewage and storm drainage separate. Size from occupancy and measured site conditions. Outside the plinth is necessary, but alone does not establish excavation or soak safety.

Access & municipal permission

Measure finished headroom, include vehicle mirrors and check actual road/gate geometry. Municipal acceptance needs an authentic authority record.

Missing historical M08 native files are excluded from Ashok’s active design basis by the owner’s instruction of 28 October 2026. Existing history stays recoverable; no current action waits for those bytes.

05 · Upgrade the shared template

All projects load the same AAD studio. Add reusable capabilities to the shared engine, then author project-owned data. Do not fork a project viewer or modify another repository’s source authority.

The current template adds jurisdiction-aware code checks and stable document control. It retains the existing 3D-first model, linked plans, component selection and IFC path.
