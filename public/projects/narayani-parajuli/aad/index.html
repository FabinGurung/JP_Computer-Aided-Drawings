Requirements for one assembled multistorey BIM model

Three individually editable storeys are not yet one building model. The following must be modeled and verified using the same governed AAD principles before calling it multistorey BIM:

Work packageRequired outputPresent situation
1. Shared building coordinatesOne measured grid, datum, orientation and world transform per storey; reconciliation of the currently different floor-local originsOpen — independent floor coordinates only
2. Building, levels and storeysPersistent building/site/storey IDs, levels, elevations, story ownership and stable cross-storey element referencesAssumed levels 0, 3, 6, 9 m; no unified hierarchy
3. Structural frames and slabsVerified columns, beam axes, slab thicknesses, foundations and engineering classifications, connected to structural DXF schedulesAbsent from current semantic AAD models; previous structural releases remain separate
4. Floor and vertical connectionsReal stair flights/landings, risers/treads, openings through floor slabs, lift/shafts if present, and consistent vertical clearancesOnly stair-named rooms and partitions; no staircase solids
5. Architectural BIM objectsBuildable wall types, real opening/fill relationships, window/door properties, slab edges, space boundaries and roof/terrace designWall graph and hosted openings; partial assumed semantics
6. IFC identity and data exportIfcProject → IfcSite → IfcBuilding → IfcBuildingStorey with unique persistent IDs, placements, containment, relationship objects, units and property setsIfcWall/IfcDoor/IfcWindow labels are conceptual mappings only
7. Reproducible validationGeometry and overlap tests, inter-storey alignment, numeric QA, coordinate/area reports, IFC round-trip and visual checksFloor-level tests exist; building-wide tests and IFC validation pending

Implementation boundary: This package adds a project component register and a project-level view preference. Assembling the building requires a separately reviewed, versioned multistorey data contract and structural/spatial validation; this change does not modify or silently extend the existing AAD engine.
