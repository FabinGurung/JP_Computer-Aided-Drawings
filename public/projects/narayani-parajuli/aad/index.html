Project source authority

The DXF source was found in the established Narayani project and processed using ezdxf. It includes older historical floor schemes; this view selects the amended July 2026 floor trio (205.16, 200.67, 175.62 m²). Visual plotting coordinates have been rounded to 10 mm; the numeric dimension ledger retains source-derived millimetre measurements. The source is authoritative for drawing dimensions; the interactive browser is for review, not a substitute for the CAD original.

How new AAD projects work

AAD is the reusable CAD-owned viewer, validator and 2D/3D geometry engine. Each project supplies its own versioned source-backed data package; the engine remains shared. An AI assistant can read the project's CAD/DXF/PDF sources, generate a validated project adapter through the CAD repository, and publish the view through GitHub Actions. Developer prompts here are an authorized authoring workflow; other users may use their own AI interpreters against the same template and validators.
