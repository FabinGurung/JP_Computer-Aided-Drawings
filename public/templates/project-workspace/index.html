3 · Engineering packages & calculations

3.1 · Sixteen stage slots

AAD-TEMPLATE-3-1-1

3.1.1 · Uniform source requirements

Each package has the same required input evidence, calculation checks and field-QA questions. A source-linked package is different from a verified fabrication/engineering release.

AAD-TEMPLATE-3-1-2

3.1.2 · Source states remain truthful

Narayani has seven retained workbenches with HOLDs, Harisharan a shared provisional material study, Ashok coordination only, Ramachandra no admitted site packages. The dummy is entirely empty.

3.2 · Steel and concrete guards

AAD-TEMPLATE-3-2-1

3.2.1 · Rod/BBS memory rules

Theoretical steel mass can be derived from diameter, length, count and density; do NOT invent bar marks, hooks, laps, stirrup cut lengths or accepted weights. Original engineer-signed details control.

AAD-TEMPLATE-3-2-2

3.2.2 · Concrete and cement rules

Gross volume by source geometry; net deductions and cement bag counts require an approved mix/dosage and verified size. No standard dosage, bag total, reinforcement quantity or project value is inherited.

4.2 · Revision workflow

AAD-TEMPLATE-4-2-1

4.2.1 · One logical ID and stable current provider ID

For maintained Docs, archive the entire prior revision with readback, guard the in-place update against concurrent revisions, increment once and capture PRE/POST hashes and receipts.

AAD-TEMPLATE-4-2-2

4.2.2 · Append-only source lineage

New mandatory project-edition workflow: store real project-specific architectural design changes in NEW immutable, source-linked manifest versions; append them to the shared west-rail Design edition / source version selector with explicit predecessor and review state. Older editions must remain selectable. The same CAD viewer handles Ashok, Narayani, Harisharan and Ramachandra; the empty starter has no real model. Browser requests do not publish. Open the CAD edition contract v1.4.0.

Preserve exact past Git commits, Narayani frozen stage trees, prior design editions and project old interfaces. UI and template release numbers are not project model editions.

AAD-TEMPLATE-5-2-1

5.2.1 · Protected PR and CI

Use bounded CAD branch, PR, green tests on exact head, merge after checks; do not bypass failed gates, invent deployment or claim live Sheets sync.
