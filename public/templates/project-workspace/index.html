Reusable project workspace template

Standard 1.1 · CAD-owned · five chapters · four-direction layout

1. Five separate chapters

01 · ViewsLinked 2D + 3D phases and components
02 · Quantities / BOQMeasured quantities and component register
03 · Programme / GanttSource-admitted plans or qualified scenarios
04 · Packages / Site ModulesDetailed materials, site packages and original workbenches
05 · Sources & recordsOriginal sources, revisions, qualifications and history

2. All four navigation directions

NorthProject identity and chapter tabs
WestVersions, chapters and floors
EastPackage inspector and safe quick actions
SouthPackage dock / site shortcuts

On mobile, west is a labelled drawer, east stacks under content and south scrolls horizontally. A narrow phone cannot display four desktop-width panes side by side.

3. Package record format

Package titleOriginal version / status, source scope, concise note, original viewer link and explicit engineering gate.

A source record can be frozen and still NOT be approved for construction. Unadmitted information is unknown, not zero. This template supplies no fabrication dimensions, quantities or project dates.

4. How to register a new project

  1. Resolve the authoritative project folder, drawings, accepted current revision and engineering holds in authenticated Drive.
  2. Create a project-owned adapter with edition, floors and sources; never copy another project's measurements.
  3. Register individual site packages only after source verification; do not convert unadmitted items into frozen cards.
  4. Run standard static/browser QA and publish via the normal protected GitHub Pages workflow.
