Drawing Control Tower

One semantic and machine-readable contract governing how project source files become linked 2D/3D plans, measurements, programme evidence and site packages. Edition and floor identities stay stable across all five chapters.

This is a review framework, not a structural design approval, site instruction, permit, or authority to invent missing columns, durations or quantities. Missing source registration produces HOLD, never a fabricated A1/B2 plan.

Each cardinal direction has one responsibility

North · where

Project, chapter, view layout, current floor.

West · which version

Edition, source revision and section hierarchy.

Centre · what

Source-grounded 2D/3D, current geometry and actual member IDs.

East · why

Selection, evidence, qualifications and inspector.

South · next

Unique unresolved review gate; previous/next checkpoint and source link. No copied chapter or package menu.

Column-axis standard

Two independent coordinate layers

Source column axes: A, B, C… on one axis and 1, 2, 3… along the other. Each source-supported column is identified at an intersection (for example A1), its lines extend beyond the perimeter with end bubbles and numeric bay dimensions.

100 mm measurement grid: point/cell locations and world X/Z in millimetres. It cannot be substituted for structural-column axes.

Proof before placement

For each new review drawing, the admitted source must identify the drawing revision, original axis positions, orientation, floor relationship and connection to actual column IDs. If only a model proxy exists, axes can be shown as provisional review; these are not approved structural members.

On missing evidence, show AXES_NOT_ADMITTED. No empty intersection becomes a new pillar automatically.

    Human-facing semantic standard

    Keep structural member IDs stable from source intake through plan, model, take-off, programme and construction module. Separate owner's revision request, independent geometry check, professional engineering review and approved issue. Use null for unknown calculations, retain original files and all prior editions.

    Machine-readable acceptance standard

    The control-tower JSON defines chapter contracts, axis admission, mandatory floor/source references and review queue. CI validates source shape, prevents duplicate IDs, verifies the 2D axis layer on registered review editions and checks desktop/mobile navigation. The actual source-intake and cross-repository publishing pipelines must separately demonstrate provider readback and approval before any construction status changes.
